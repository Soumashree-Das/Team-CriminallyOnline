##  Installation

```bash
git clone https://github.com/Soumashree-Das/capacity-connect.git
cd capacity-connect
npm install
```

##  Usage
Frontend:-
```bash
cd frontend
npm install
npm run dev
```
Backend:-
```bash
cd backend
pip install -r requirements.txt
python seed.py
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
